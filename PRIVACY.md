# Privacy Policy

Last updated: September 12, 2026

ChatGPT Prompt Link Generator turns text that you explicitly select into a shareable ChatGPT URL and copies that URL, or an HTML icon link containing it, to your clipboard.

## Data the extension handles

- **Selected text:** The extension receives only the text you select when you choose **Generate ChatGPT Link** from Chrome's context menu.
- **Output preference:** The extension stores whether you prefer a plain URL or an HTML icon link using Chrome's synchronized extension storage.

## How data is used

Selected text is URL-encoded locally on your device solely to create the link you requested. The generated output is written locally to your clipboard.

The extension does not send selected text, generated links, browsing history, or usage information to the developer or to any developer-operated service. It does not contain analytics, advertising, tracking, or remote code.

The extension does not retain selected text or generated links. Chrome may synchronize the output-format preference according to your Chrome account and synchronization settings.

## Sharing and ChatGPT

The prompt is readable within the generated URL. Anyone who receives the link can read it, and it may appear in browser history, messages, link previews, or system logs.

The extension only creates and copies the link. If you or a recipient opens it, the browser connects to `https://chatgpt.com/`. Information handled by ChatGPT is governed by OpenAI's own terms and privacy practices. This extension is not affiliated with or endorsed by OpenAI.

## Data sale and human access

The developer does not sell, transfer, or use user data for advertising, credit decisions, or any purpose unrelated to generating the user-requested link. Because no selected text or generated link is sent to the developer, the developer cannot read it.

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes

Material changes to this policy will be documented in the repository and reflected in the Chrome Web Store listing before updated data practices take effect.
