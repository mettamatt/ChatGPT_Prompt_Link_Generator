# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/mettamatt/ChatGPT_Prompt_Link_Generator/security/advisories/new

Include the affected extension version, steps to reproduce the issue, its potential impact, and any suggested mitigation. You can expect an initial response within seven days.

For ordinary bugs and feature requests that do not involve a security or privacy risk, use the public issue tracker.
