# ChatGPT Prompt Link Generator 1.1.0

Version 1.1.0 modernizes the extension while preserving its streamlined workflow: select text, choose one context-menu command, and paste the generated link.

## Highlights

- Generates `https://chatgpt.com/?q=...` links.
- Keeps both plain URL and self-contained HTML icon-link output.
- Copies reliably through a Manifest V3 offscreen document.
- No longer requests access to every webpage.
- Clearly warns when a prompt is too long for a reliable URL.
- Opens the simplified preferences page from the toolbar icon.
- Adds automated coverage for encoding and output generation.

## Permission change

This release replaces webpage script injection with the `offscreen` and `clipboardWrite` permissions. `clipboardWrite` is used only after the user invokes **Generate ChatGPT Link**, and only to copy the generated output. The extension never reads clipboard contents.

## Important limitation

ChatGPT's `?q=` URL parameter is not documented as a public API and may change without notice.
